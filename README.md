# 📚 Collection Manipulator (Student Management System)

## 📌 Description
Collection Manipulator is a Python-based console application that allows users to manage student records using core data structures like lists, dictionaries, and sets.

This project demonstrates CRUD operations (Create, Read, Update, Delete) along with subject management.

---

## 🚀 Features
- ➕ Add new student
- 📋 Display all students
- ✏️ Update student information
- ❌ Delete student
- 📘 Display all subjects offered
- 🔁 Menu-driven system

---

## 🛠️ Technologies Used
- Python (Core Concepts)
  - List
  - Dictionary
  - Set
  - Loops
  - Conditionals

---

## 📂 Data Structure Used
- List → Stores all students
- Dictionary → Stores individual student data
- Set → Stores unique subjects
